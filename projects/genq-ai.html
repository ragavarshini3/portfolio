GenQ – AI Question Paper Generator

An AI-powered question paper generator that creates customized question papers based on department, subject, difficulty level, question types, and other requirements.

Overview

GenQ uses Google Gemini AI to automatically generate structured question papers, reducing the time and effort required for teachers to manually prepare examination papers.

Generated question papers can be customized by department, subject, difficulty level, and question types, and formatted and downloaded directly as PDFs using ReportLab.

Key Architectural Highlights

  • Google Gemini AI Integration: Leverages Gemini API to generate pedagogical questions adhering to difficulty constraints and Bloom's Taxonomy.
  • Dynamic Customization: Supports filtering and prompt construction by department, subject syllabus, mark distributions, and difficulty levels.
  • Automated PDF Generation: Uses ReportLab in Python to format and compile cleanly styled exam PDFs ready for printing.
  • Flask Web Application: Lightweight web interface enabling educators to specify paper requirements and download results instantly.
